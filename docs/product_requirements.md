# 项目需求及功能文档 - 给产品经理

## 1. 项目概述

本项目是一个面向个人使用的双端音乐同步播放器。

用户希望将自己的音频文件集中放在电脑端进行管理，同时在手机端同步部分歌单，实现随身离线播放。

项目不依赖云音乐平台，不做公网远程播放，不做多用户系统。V1 目标是先跑通“电脑端导入和管理音乐，手机端通过 Wi-Fi 同步歌单并离线播放”的核心闭环。

## 2. 产品定位

产品形态：Windows 电脑端 APP + Android 手机端 APP。

电脑端定位：主音乐库、管理端、播放器、同步源。

手机端定位：只读随身音乐库、本地播放器、同步接收端。

同步模式：电脑端到手机端的单向同步。

核心价值：让用户拥有一个私有、可控、低成本的个人音乐库，并能在手机上离线听自己同步过的音乐。

## 3. 目标用户

V1 目标用户为项目发起者本人。

典型用户画像：

- 有一批自己的本地音频文件；
- 希望不依赖第三方音乐平台；
- 希望在电脑端统一整理音乐；
- 希望在手机端像普通音乐 APP 一样听歌；
- 希望同步完成后手机可以离线播放；
- 不需要社交、推荐、云曲库等商业音乐软件能力。

## 4. 产品目标

V1 产品目标是跑通以下闭环：

用户在 Windows 电脑端导入音乐，建立多个歌单，然后在同一 Wi-Fi 下用 Android 手机扫码连接电脑端，选择整个歌单同步到手机本地。同步完成后，手机端即使离线也能播放这些歌曲。

V1 不追求完整商业音乐软件体验，优先追求：

- 导入稳定；
- 歌单管理清晰；
- 同步流程简单；
- 手机离线播放可靠；
- 用户操作方便；
- 不破坏原始音乐文件。

## 5. V1 核心用户流程

### 5.1 电脑端导入音乐

用户打开电脑端 APP。

用户选择导入音乐。

用户可以选择一个或多个音频文件，也可以选择整个文件夹。

系统扫描支持的音频格式。

系统将音频复制到 APP 自己的音乐库目录。

系统读取音频内部元数据。

系统根据规则生成歌曲信息。

导入完成后，歌曲进入电脑端音乐库。

### 5.2 电脑端整理歌单

用户在电脑端查看全部歌曲。

用户可以新建多个歌单。

用户可以将歌曲加入不同歌单。

用户可以重命名歌单、删除歌单、从歌单移除歌曲。

用户可以播放电脑端本地音乐。

### 5.3 手机端同步歌单

用户在电脑端打开“同步模式”。

电脑端显示二维码和连接码。

用户在手机端点击“同步音乐”。

用户用手机扫码连接电脑端。

连接成功后，手机端显示电脑端歌单列表。

用户选择一个歌单进行同步。

手机端下载该歌单中的全部歌曲。

同步完成后，歌单和歌曲保存在手机 APP 本地。

### 5.4 手机端离线播放

用户离开 Wi-Fi 或电脑关闭后，打开手机端 APP。

手机端只显示已同步到本地的歌单和歌曲。

用户可以搜索、播放、切歌、暂停。

手机端不依赖电脑实时在线。

## 6. V1 功能清单

### 6.1 电脑端功能

#### 6.1.1 音乐导入

支持选择音频文件导入。

支持选择文件夹导入。

支持格式：MP3、FLAC、M4A、WAV。

导入时默认复制音频到 APP 音乐库目录。

导入时生成导入结果。

#### 6.1.2 音乐库管理

展示全部歌曲。

展示待整理音频。

展示基础歌曲信息。

支持基础搜索。

支持播放本地歌曲。

#### 6.1.3 音频识别

优先读取音频内部元数据。

元数据缺失时，尝试使用有明确规律的文件名。

数字、编码、乱码、无意义文件名不乱识别。

无法识别时命名为“未命名音频 001/002/003...”。

无法识别的音频进入“待整理音频”。

#### 6.1.4 歌单管理

支持创建多个歌单。

支持重命名歌单。

支持删除歌单。

支持向歌单添加歌曲。

支持从歌单移除歌曲。

同一首歌可以加入多个歌单。

删除歌单不得删除歌曲文件。

#### 6.1.5 搜索

电脑端需要搜索功能。

搜索范围包括全部歌曲、歌单、待整理音频。

搜索字段包括歌曲名、歌手、专辑、歌单名、未命名音频编号。

#### 6.1.6 同步模式

用户手动打开同步模式。

每次打开同步模式生成新的临时连接码。

电脑端显示二维码和连接码。

同步模式关闭后，旧连接码失效。

### 6.2 手机端功能

#### 6.2.1 扫码连接

手机端提供“同步音乐”入口。

用户扫码连接电脑端。

连接成功后显示电脑端可同步歌单列表。

#### 6.2.2 歌单同步

手机端按整个歌单同步。

用户选择一个歌单后，手机端下载该歌单内全部歌曲。

V1 不支持只同步部分歌曲。

V1 不支持单曲自由同步。

#### 6.2.3 本地音乐库

同步后的歌曲存入手机 APP 自己的本地目录。

手机端只展示已同步到本地的歌曲和歌单。

手机端不展示电脑端未同步内容。

#### 6.2.4 离线播放

手机端支持离线播放已同步歌曲。

电脑关机、手机断网时，已同步歌曲仍可播放。

#### 6.2.5 搜索

手机端需要搜索功能。

搜索范围为已同步歌曲和已同步歌单。

#### 6.2.6 删除本地缓存

手机端允许删除本地缓存。

删除缓存不影响电脑端主库。

删除缓存不影响电脑端歌单。

删除缓存后，该歌曲需要重新同步才能在手机端播放。

### 6.3 同步功能

同步方式只做同一 Wi-Fi。

同步方向只做电脑端到手机端。

同步粒度只做整个歌单。

同步时应跳过手机端已存在且未变化的歌曲。

同步失败时，已下载成功的歌曲应保留。

重新同步时，不应重复下载已完整同步且 hash 一致的歌曲。

## 7. 权限和边界

### 7.1 电脑端权限

电脑端拥有完整管理权限。

电脑端可以导入、播放、搜索、创建歌单、修改歌单、删除歌单、管理歌曲与歌单关系。

电脑端是主库。

### 7.2 手机端权限

手机端是只读副本。

手机端可以同步、搜索、播放、删除本地缓存。

手机端不能导入音乐。

手机端不能创建歌单。

手机端不能重命名歌单。

手机端不能删除歌单。

手机端不能向歌单添加歌曲。

手机端不能从歌单移除歌曲。

手机端不能同步回电脑。

## 8. 用户体验要求

### 8.1 导入体验

导入入口要清楚。

用户可以选择文件，也可以选择文件夹。

导入结果要反馈成功、失败、待整理数量。

数字或乱码文件名不应导致导入失败。

### 8.2 歌单体验

用户应能方便地创建多个歌单。

用户应能把歌曲加入不同歌单。

用户应能清楚看到每个歌单里的歌曲。

### 8.3 同步体验

同步流程必须简单：

打开同步模式，扫码，选择歌单，下载，完成。

用户不应该手动输入复杂 IP 地址。

二维码不可用时，可以保留连接码作为备用。

### 8.4 手机端体验

手机端应像一个独立随身播放器。

手机端离线时不应显示不能播放的远程内容。

手机端应只显示已同步内容，让用户不会点到无法播放的歌曲。

## 9. V1 暂不实现内容

V1 不做以下功能：

- 云同步
- 公网远程播放
- 远程在线播放
- USB 同步
- 蓝牙同步
- 多用户登录
- 手机端编辑歌单
- 手机端导入音乐
- 手机端同步回电脑
- 歌词
- 封面
- 评论社交
- 推荐算法
- 在线歌曲识别
- 自动匹配全网歌曲信息
- 商业音乐平台接入
- 跨平台 iOS/macOS/Linux 支持

## 10. V1 验收标准

V1 通过验收需要满足：

1. Windows 电脑端可启动。
2. Android 手机端可启动。
3. 电脑端可以导入 MP3、FLAC、M4A、WAV。
4. 电脑端可以导入文件和文件夹。
5. 数字或乱码文件名会进入待整理音频，并按“未命名音频 001”规则命名。
6. 电脑端可以创建多个歌单。
7. 电脑端可以把歌曲加入歌单。
8. 电脑端可以播放本地歌曲。
9. 电脑端可以搜索歌曲和歌单。
10. 电脑端可以打开同步模式并显示二维码和连接码。
11. 手机端可以扫码连接电脑端。
12. 手机端可以查看电脑端歌单列表。
13. 手机端可以选择整个歌单同步。
14. 手机端可以下载该歌单内歌曲到本地。
15. 手机端可以显示已同步歌单和歌曲。
16. 手机端可以搜索已同步内容。
17. 手机端离线时可以播放已同步歌曲。
18. 手机端可以删除本地缓存。
19. 手机端不能修改歌单。
20. 同步不会破坏电脑端原始音乐库。

## 11. V1 最终交付形态

V1 不仅要完成源码实现，还需要提供用户可以实际安装和启动的应用产物。

### 11.1 Android 手机端

产品侧期望最终拿到一个 Android APK 安装包。

用户可以将 APK 下载到 Android 手机，并安装手机端 APP。

安装完成后，用户可以打开手机端 APP，点击“同步音乐”，通过扫码连接 Windows 电脑端，在同一 Wi-Fi 下同步歌单，并在同步完成后离线播放。

### 11.2 Windows 电脑端

产品侧期望最终拿到一个 Windows 桌面端可启动程序。

用户理解的启动方式是双击 exe 文件打开软件，因此 V1 需要提供可双击启动的 Windows exe 应用。

电脑端 APP 应在用户项目文件夹或 release 目录中生成，并提供清晰路径说明。

用户不应被要求每次通过开发命令启动电脑端 APP。

### 11.3 交付体验要求

最终交付时，应尽量让用户看到清晰的文件结构，例如：

```text
release/
  android/
    music_sync_player_v1.apk
  windows/
    MusicSyncPlayer/
      MusicSyncPlayer.exe
      其他运行所需文件
  RELEASE_NOTES.md
```

`RELEASE_NOTES.md` 应说明：

- 手机 APK 在哪里；
- 电脑 exe 在哪里；
- 如何安装 APK；
- 如何启动 Windows 端；
- 如何进行第一次 Wi-Fi 同步；
- 当前 V1 已完成和未完成的功能。

### 11.4 产品验收补充

V1 产品验收时，除了验证“导入音乐—建歌单—扫码同步—手机离线播放”闭环，还需要验证：

- Android APK 可以安装并打开；
- Windows exe 可以双击启动；
- Windows 端不是只能通过源码开发环境启动；
- 交付说明足够清楚，用户能根据说明完成安装和启动。
